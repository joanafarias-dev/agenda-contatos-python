# Agenda de Contatos

Projeto desenvolvido em Python para praticar lógica de programação e manipulação de arquivos JSON.

## Funcionalidades

- Adicionar contatos (nome e telefone).
- Listar contatos cadastrados.
- Excluir contatos.
- Salvar os contatos em arquivo JSON.
- Carregar os contatos salvos ao iniciar o programa.

## Tecnologias utilizadas

- Python
- JSON

## Como executar

1. Tenha o Python instalado.
2. Baixe os arquivos do projeto.
3. Execute o arquivo `agenda.py` pelo terminal:

   python agenda.py
